# Seedance 2.5 Notes

Seedance 2.5 in plain terms: one continuous 30-second clip instead of 15, up to 50 multimodal references, local edits after generation, and three places to try it.

**Read the full page:** https://seedance-2-5-dev.github.io/

This release is for people whose shot list keeps breaking at the fifteen-second mark, or who have been feeding a model three references when the scene needed twenty. Both limits moved: single-segment output now reaches thirty seconds without stitching, and the reference ceiling is fifty multimodal inputs. It is not the release to chase if you make eight-second social clips, because everything you already do fits comfortably inside the old ceiling and you will pay for headroom you never touch. The caveat is pricing: the hosts running it advertise free trials and paid upgrades but no per-second rate on the pages checked here. If you want generation in the browser on a plan that is priced openly, Kyncept runs Veo 3.1 text and image to video instead.

## What's here

- **Fifty references is a different way of working** — A reference ceiling that high changes what you hand the model. The documented split on one host caps a job at fifty files, with up to thirty images, ten videos
